==============================================================================
  SkadaDiscord 2.3 — отчёты Skada по боссам в Discord
  для World of Warcraft 3.3.5a (WotLK, проверено на WoW Circle)
  Автор: Leanca Vladimir  ·  Discord: lyanka_v
==============================================================================

Что это
-------
После убийства босса отчёт из Skada (урон, исцеление и другое) сам уходит
в нужный канал Discord в виде картинки — как окно Skada в игре: полосы цвета
класса, иконки специализаций, проценты.

Состоит из двух частей:
  1. Аддон "Skada: Discord" (в игре) — собирает данные по каждому убийству,
     показывает большой таймер отправки, окно /sd и все настройки.
  2. Программа SkadaDiscord.exe (на компьютере) — рисует картинки и
     отправляет их в Discord. Сидит в трее рядом с часами.

Почему нужна программа: аддоны WoW не умеют выходить в интернет. Игра
сохраняет данные аддонов в файл только при /reload или выходе из игры,
программа этот файл читает и отправляет отчёты.


ЧТО НОВОГО
----------
2.3
  • База данных: каждое убийство уходит ещё и на общий сервер отчётов
    DB-Circle-x100 (картинка урона и исцеления). Один бой = один отчёт,
    даже если аддон стоит у нескольких игроков рейда. Выключается в игре:
    /sd -> "Настройки" -> "Общие" -> "Отправлять отчёт в базу данных".
  • Поиск по нику на сервере базы: команда /игрок.
  • Защита от дублей в своих каналах (см. ниже).
  • Ники для поиска Discord всегда пишутся в скрытую подпись картинки
    (настройка "Текст для поиска по нику" убрана).
2.2
  • Все настройки отчётов перенесены в игру: /sd -> "Настройки".
    Старые настройки из программы переносятся в игру сами (профиль
    "Перенесено из программы").
  • Профили настроек, экспорт/импорт строкой (можно отдать другу).
  • У канала может быть несколько ссылок-вебхуков (разные серверы).


ЧТО НУЖНО
---------
  • WoW 3.3.5a с РУССКИМ клиентом (имена боссов в настройках — по-русски;
    для английского клиента их можно переименовать в настройках аддона).
  • Аддон Skada (версия "Skada Revisited" от bkader для 3.3.5).
  • DBM — желательно: из него берутся цифры таймера, голос отсчёта и
    сигнал "босс убит" (Skada на Circle иногда не видит убийство Совета
    Принцев и Валитрии, DBM их ловит).
  • Windows 10 или 11 (всё нужное для программы уже встроено в Windows).
  • Для своих каналов — права "Управлять вебхуками" на своём сервере
    Discord. Для базы данных ничего не нужно.


УСТАНОВКА
---------
1. Распакуйте архив В ПАПКУ С ИГРОЙ (там, где лежит Wow.exe).
   Должно получиться:
       <папка игры>\Wow.exe
       <папка игры>\Interface\AddOns\SkadaDiscord\   <- аддон
       <папка игры>\SkadaDiscord\SkadaDiscord.exe    <- программа
       <папка игры>\SkadaDiscord\README.txt          <- этот файл

2. Запустите SkadaDiscord\SkadaDiscord.exe.
   (Если Windows покажет "Windows защитил ваш компьютер" — нажмите
   "Подробнее" -> "Выполнить в любом случае". Программа не подписана
   сертификатом, поэтому Windows так предупреждает о любых таких файлах.)
   Страница "Программа" -> "Создать ярлык «Играть» на рабочем столе".
   Дальше запускайте игру этим ярлыком: он открывает WoW и программу,
   а программа закрывается вместе с игрой.

3. В игре на экране выбора персонажа -> "Модификации" включите
   "Skada: Discord". Если игра уже запущена — сделайте /reload.

4. Создайте вебхуки в Discord (по одному на каждый канал, куда слать
   отчёты): настройки канала (шестерёнка) -> Интеграции -> Вебхуки ->
   Новый вебхук -> "Копировать URL вебхука". Ссылка выглядит так:
       https://discord.com/api/webhooks/1234567890/AbCdEf...
   Ссылку никому не показывайте: кто её знает, может писать в канал.
   (Если свои каналы не нужны — этот шаг можно пропустить: отчёты всё
   равно уйдут в базу данных.)

5. В игре: /sd -> "Настройки" (или /sd config):
     • "Каналы Discord" — новый канал (название), затем вставьте ссылку
       (Ctrl+V) и нажмите "Принять". Можно вставить сразу список строк:
           ДПС-Лич: https://discord.com/api/webhooks/...
           ХПС-Лич: https://discord.com/api/webhooks/...
     • "Инсты и боссы" — для каждого босса окна отчёта и канал (ниже).
   Сделайте /reload — игра запишет настройки в файл, программа их возьмёт.


КАК ЭТО РАБОТАЕТ В РЕЙДЕ
------------------------
  • Убили босса -> аддон сохраняет отчёт (в чате: "отчёт по ... готов").
    Вайпы не отправляются, но в отчёте пишется "Победа с 4-й попытки".
  • Когда убиты ВСЕ боссы инста (ЦЛК — 12, РС — 4), по центру экрана
    появляется большой таймер (по умолчанию 5:00) с кнопками
    "Отправить сейчас", "+1 мин", "Отмена".
  • На нуле интерфейс перезагрузится (/reload) — и программа за пару секунд
    отправит все отчёты рейда. Если идёт бой или раздача лута (окна лута,
    ролла, EPGP Lootmaster, RaidRoll) — таймер подождёт.
  • Ушли из рейда раньше — отчёты уйдут при выходе из игры.
  • Отправить вручную в любой момент: /sd -> "Отправить" (или /sd send).


БАЗА ДАННЫХ (ОБЩИЙ СЕРВЕР ОТЧЁТОВ)
----------------------------------
  • Каждое убийство (без вайпов) уходит на общий сервер Discord
    DB-Circle-x100: картинка "Урон" (25 строк) и "Исцеление и поглощения"
    (лекари, 10 строк) — одинаковая у всех, не зависит от ваших окон.
    Каналы там создаются сами: категория на инст и сложность, канал на
    босса.
  • Один бой = один отчёт: если аддон стоит у нескольких игроков рейда,
    отправит тот, кто успел первым, остальным программа напишет в журнале
    "уже в базе (отправил другой игрок)".
  • Поиск по нику: на сервере базы команда /игрок <ник> — последние бои
    игрока, урон/исцеление в секунду и место в рейде.
  • Выключить: /sd -> "Настройки" -> "Общие" -> "Отправлять отчёт в базу
    данных" (и /reload).
  • Ссылок и токенов базы у вас нет: программа отправляет отчёт через
    сервер SkadaDiscord (skadadiscord.leancavladimir.workers.dev).


ЗАЩИТА ОТ ДУБЛЕЙ В СВОИХ КАНАЛАХ
--------------------------------
Если аддон стоит у нескольких игроков рейда и их отчёты идут в один и
тот же вебхук, одинаковое окно (например "Урон (весь)" у обоих) уйдёт в
этот вебхук один раз — от того, кто отправил первым. Окна, которые есть
только у одного из игроков, и другие вебхуки отправляются как обычно.
В журнале: "уже отправлено другим игроком рейда" или "окон 1 из 2".
Если сервер защиты от дублей недоступен, отчёты уходят без проверки.


В ИГРЕ: ОКНО /sd
----------------
  • Список отчётов: "ждёт отправки" — создан после последнего /reload,
    "записан" — уже на диске (программа его отправила или отправит).
    Крестик — удалить. Удалили и добавили заново — отправится ещё раз.
  • "История боёв >>" — любой бой из истории Skada: щёлкните, и он
    добавится в список (можно отправить и вайп — будет красная пометка).
  • Прогресс рейда: "ЦЛК 25 — 9/12". "Таймер" — запустить/остановить
    таймер вручную, "Сбросить" — начать счёт боссов заново
    (новое КД сбрасывается само).
  • "Настройки" — окно настроек (ниже).
  • Кнопка у миникарты: ЛКМ — окно, Shift+ЛКМ — настройки,
    ПКМ — отправить сейчас.

  Команды:
    /sd           окно
    /sd config    настройки
    /sd history   история боёв
    /sd send      отправить сейчас (перезагрузка интерфейса)
    /sd timer     запустить таймер
    /sd stop      остановить таймер
    /sd last      добавить последнее убийство
    /sd clear     очистить список


В ИГРЕ: НАСТРОЙКИ (/sd -> "Настройки")
-------------------------------------
Настройки сохраняются при /reload и выходе из игры; программа берёт их
из того же файла, что и отчёты.

1) Общие — таймер автоотправки (сек), голос DBM, открывать окно после
   убийства, кнопка у миникарты, "другие рейды" (слать боссов, которых нет
   в списках), каналы для боссов без настроек, имя бота, размер картинки,
   отправка в базу данных.

2) Профили — общие для всех персонажей аккаунта: новый, копия,
   переименовать, удалить. Экспорт — строка, которую можно отправить другу
   (ссылки-вебхуки в неё попадают, только если включить галочку);
   импорт — вставить такую строку.

3) Каналы Discord — у канала одна или несколько ссылок (отчёт уходит по
   всем), видно, у каких боссов канал используется.

4) Инсты и боссы — инст (ЦЛК, РС; можно добавить свой: название и зона
   как в игре), когда запускать таймер ("после убийства всех боссов" или
   "после выбранного босса"). У босса: "Отправлять отчёт", окна отчёта:
       Что показывать | Канал | Заголовок | Строк | Цели | Только хилеры
   Окна с одним каналом собираются в одну картинку (одно сообщение).
   Кнопки: "+ Окно", "Стандартные окна", "Копировать окна на всех".
   Слева боссы: зелёный — отправляется, красный — не выбран канал,
   серый — выключен.

   Что можно показывать:
     Урон (весь)                — как окно "Урон" в Skada
     Урон по боссу              — только по самому боссу
     Урон по выбранным целям    — например "Живое адское пламя" на Халионе
     Урон по трешу              — всё, кроме босса и выбранных целей
     Полезный урон              — без оверкилла
     Исцеление + поглощения     — как окно "Исцеление и поглощения" в Skada
     Только исцеление, Только поглощения (щиты), Оверхил
     Полученный урон, Урон по своим
     Смерти, Прерывания, Диспелы, Зелья, Ошибки (Fails), Раскол брони
     Активность (% времени боя)
   В окнах исцеления по умолчанию только хилеры (по спеку/роли).

   По умолчанию: урон — 25 строк, хил — 4 строки (Валитрия — 10).
   РС: урон по боссу, по большому пламени (Халион), по трешу, хил.


ПРОГРАММА
---------
Окно: ярлык/файл SkadaDiscord.exe или двойной щелчок по значку в трее.
  • Журнал — что прочитано из игры и что отправлено (ошибки — красным).
  • Программа — папка игры (пусто = определяется сама), файл запуска,
    "закрываться вместе с игрой", ярлык "Играть".
  • О программе — версия, автор, какие настройки получены из игры.


ПОИСК ПО НИКУ В DISCORD
-----------------------
К каждой картинке добавляется скрытая подпись со списком игроков (в канале
не видна), поэтому поиск Discord находит отчёты по нику — и в своих
каналах, и на сервере базы. На сервере базы есть ещё команда /игрок.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
  • Отчёт не пришёл — откройте программу -> "Журнал". Там видно, прочитан
    ли файл из игры и что ответил Discord.
  • "Отчётов ждут настроек" — в игре не указан ни один канал со ссылкой:
    /sd -> "Настройки" -> "Каналы Discord", затем /reload.
  • "вебхук не найден" — ссылку удалили в Discord, создайте новую.
  • В игре ничего не происходит после убийства — проверьте, что аддон
    включён, и что у босса стоит "Отправлять отчёт" и выбран канал.
  • Таймер написал "Нажмите «Отправить сейчас»" — игра не дала
    перезагрузить интерфейс автоматически, нажмите кнопку.
  • Чтобы увидеть ошибки Lua в игре: /console scriptErrors 1
  • Английский клиент — переименуйте боссов и зоны в настройках аддона
    так, как они называются в Skada.
  • Вопросы и ошибки: Discord lyanka_v.

                                      до переноса в игру — и старые ссылки)
  SkadaDiscord\config.example.json    шаблон настроек

  SkadaDiscord\reports\               копии отчётов
  SkadaDiscord\log.txt                журнал
  SkadaDiscord\src\                   исходный код; пересборка:
                                      powershell -ExecutionPolicy Bypass -File src\build.ps1
  Interface\AddOns\SkadaDiscord\      аддон (Config.lua — для разового
                                      переноса старых настроек из программы)
  WTF\Account\<аккаунт>\SavedVariables\SkadaDiscord.lua
                                      настройки и отчёты аддона (в нём ваши
                                      ссылки-вебхуки — не передавайте!)

Передавая программу другу, НЕ отдавайте config.json и папку WTF —
в них ваши ссылки. Настройки без ссылок можно передать строкой экспорта
(/sd -> "Настройки" -> "Профили").
